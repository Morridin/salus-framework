AddButton
A button that asynchronously fetches available plug-ins for a specific position upon click, opening a selection context menu.
CloseButton
A button utilised to close an active panel or plug-in view. The button does not close the component it is placed in per sé when clicked. Instead, the event handler provided via its onclick argument is executed.
ContextMenu 🔒
An overlay menu for keyboard- and mouse-based selection of a plug-in from a list. Currently, it is always shown centered on the screen, due to unresolved problems with mouse pointer based positioning close to the lower and right screen edge.
MinimiseButton
A button used to toggle the minimised state of a panel. The state is passed as [Signal] via the button’s only argument.
